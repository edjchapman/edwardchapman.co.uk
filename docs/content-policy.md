# Content policy

<!-- Stub — expanded in Phase 0 PR-3. -->

Only deliberately selected, public-safe material may be published: public
GitHub profile copy, public repositories and demos, explicitly approved
positioning material, and content written for this site. Salary details,
interview pipeline information, private notes, phone numbers, precise
location, private email threads and unverifiable claims are prohibited.
`scripts/check-content-policy.ts` enforces this mechanically in `make check`.
